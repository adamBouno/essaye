# Jeu de Ludo - Version Graphique 🎲

Un jeu de société Ludo complet pour 4 joueurs avec une interface graphique intuitive.

## Comment jouer

### Lancement du jeu
```bash
python ludo.py
```

### Règles du jeu


1. **Objectif** : Être le premier joueur à amener ses 4 pions à l'arrivée au centre du plateau.

2. **Joueurs** : 4 joueurs (Rouge, Bleu, Jaune, Vert)

3. **Déroulement d'un tour** :
   - Cliquez sur "🎲 Lancer le dé"
   - Si vous obtenez un 6, vous pouvez sortir un pion de votre base
   - Les pions surlignés en cercle coloré peuvent être déplacés
   - Cliquez sur un pion pour le déplacer
   - Les positions possibles sont marquées en jaune

4. **Règles spéciales** :
   - **Sortie de base** : Uniquement avec un 6
   - **Capture** : Un pion adverse sur votre case retourne à sa base
   - **Chemin d'arrivée** : Chaque couleur a son propre chemin coloré vers le centre
   - **Tour supplémentaire** : Si vous faites un 6, vous rejouez

### Interface

- **Plateau** : Représentation fidèle d'un vrai plateau de Ludo
- **Pions** : Cercles colorés pour chaque joueur
- **Surlignage** : Les pions jouables sont entourés d'un cercle coloré
- **Messages** : Informations sur les actions en cours
- **Animations** : Effets visuels pour les mouvements

### Contrôles

- **🎲 Lancer le dé** : Bouton pour obtenir un nombre aléatoire
- **Clic sur pion** : Sélectionner et déplacer un pion
- **Messages** : Boîtes de dialogue pour les informations importantes
